# TV Launcher

Màn hình chính tiếng Việt cho Android TV, tối ưu cho TV Xiaomi nội địa Trung Quốc.

## Tải APK
Vào mục **Releases** của repo này rồi tải `TVLauncher.apk` (không bị hết hạn).
Link trực tiếp bản mới nhất: `https://github.com/<TÊN_BẠN>/<TÊN_REPO>/releases/latest/download/TVLauncher.apk`

## Tự build
Tab **Actions** → **Build APK** → **Run workflow**.
